# 시험용 문서 (간접 인젝션 시험 전용)

- 이 폴더의 문서는 **시험할 때만** 색인에 들어간다. `POST /admin/fixtures {"enabled": true}`로 넣고, `{"enabled": false}`로 뺀다.
- 문서 속 지시는 **자리표시**만 있다: `[ATTACK-RAG-NN: 유형 설명 — 실제 문구는 작성자 비공개 세트]`.
- 실제 문구로 시험하려면 작성자가 `FIXTURES_DIR`를 비공개 폴더(저장소 밖 또는 .gitignore 대상)로 바꾼다. 실제 문구는 이 저장소에 커밋하지 않는다.
- 스텁 모드는 자리표시 표식을 보고 "문서 지시에 넘어가는 약한 모델"을 흉내 낸다. 실제 모델의 강약은 작성자 실측으로만 말한다.
