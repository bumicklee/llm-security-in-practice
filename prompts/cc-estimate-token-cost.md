# 프롬프트: 대화 턴별 토큰·가짜 요금 표 만들기

- **쓰는 곳:** 7장 7.2·7.5, 수업 4-2·4-5
- **도구:** Claude Code(계산 스크립트 생성·실행)
- **목적:** 대화 기록을 통째로 다시 보낼 때 턴마다 입력 토큰이 어떻게 늘어나는지, 재시도가 겹치면 호출이 몇 번이 되는지 가짜 규칙으로 계산해 표로 만든다.

## 프롬프트 본문

```text
아래 가정으로 대화 턴별 토큰과 가짜 요금을 계산하는 작은 python3 스크립트를 만들고 실행해 표를 보여 줘.
외부 패키지 없이 표준 라이브러리만. 실행은 python3 -I 로.

- 토큰 규칙(가짜): 글자 {글자_당_토큰}개 = 1토큰(올림)
- 시스템 프롬프트 {시스템_글자}자, 사용자 질문 평균 {질문_글자}자, 답 평균 {답_글자}자
- 방식 A: 기록 전부 다시 보냄 / 방식 B: 최근 {창_크기}개 메시지만
- 가짜 단가: 입력 {입력_단가}원/1K, 출력 {출력_단가}원/1K
- 턴: {턴_목록}
- 재시도: 앞단 재시도 {앞단_시도}번 × SDK 시도 {SDK_시도}번 = 최악 호출 수, 그리고 SDK 재시도를 1로 줄였을 때

표 1: 턴 | A 입력 토큰 | B 입력 토큰 | A 누적 요금 | B 누적 요금
표 2: 층 | 시도 수 | 곱한 최악 호출 수
마지막에 "이 값은 가짜 규칙이며 실제 토크나이저·단가와 다르다"를 한 줄 붙여라.
```

## 입력 예

| 변수 | 값 |
| --- | --- |
| `{글자_당_토큰}` | 3 |
| `{시스템_글자}` / `{질문_글자}` / `{답_글자}` | 120 / 30 / 60 |
| `{창_크기}` | 20 |
| `{입력_단가}` / `{출력_단가}` | 10 / 30 |
| `{턴_목록}` | 1, 10, 50 |
| `{앞단_시도}` / `{SDK_시도}` | 3 / 3 (openai 3.40.0 `DEFAULT_MAX_RETRIES = 2` → 시도 3번) |

## 기대 출력 예(모양)

```text
| 턴 | A 입력 | B 입력 | A 누적(원) | B 누적(원) |
| 1  | 50     | 50     | …          | …          |
| 50 | (계단처럼 커짐) | (창 크기에서 멈춤) | … | … |
| 층 | 시도 | 최악 |
| 앞단 × SDK 기본 | 3 × 3 | 9 |
| 앞단 × SDK max_retries=1 | 3 × 2 | 6 |
이 값은 가짜 규칙이며 실제 토크나이저·단가와 다르다.
```

재시도 곱은 랩 실측 `samples/lab-app-py/_실측/4-5_retry-grep.txt`(`3 × 3 = 9 · 3 × 2 = 6`)와 같아야 한다.
